# 理论如何变成模式（v4.1）

模式只带一条脊柱和五组判据（像与核／失败／再认知与闸门／边界／层与窗口）。脊柱是回路；表是可查的
判定，不是论证。右列给出理论主稿的节号与条款号，回查用。

| 环节 | 落到模式里的动作 | 正本 |
|---|---|---|
| 像与核 | 认识只到像、认知才动核；三层核（映射／投影／自在）**类型都写得下，差在外延**；可辨是核的补集，也是唯一写得下来的那半；商三前提（同余需 𝒪、容差取传递闭包、带宽落成 O/δ/Π） | §三，F3–F7 |
| 失败 | 六种：狭窄／畸变／无解／不稳定／模型误设（轴内两支）／选择偏差（单列，不在三轴）；六词＝不全·失真·不相容·不牢·共模·选偏；分诊按"差值／标准误"的走向 | §三，F8、F12 |
| 再认知 | 事物级四结局（确认·合并·修正·**预言**）；世界级两条约束（含"有预言的跳跃"）与 F19／F20；独立＝必要互不包含＋充分三层清单＋一致算证据三条 | §四，F8、F9、F18–F20 |
| 更新闸门 | 判据之前先写干预作用在**哪一侧**；伪影（装置侧清空）／假象（换核翻转）／真象（可追踪位移）／未定（三条都不落） | §四 |
| 边界 | 四类变换各给什么（良定义性／不变量／交集／单向对）；交集需同值域与公共预言空间，两条检验路；先验填成投影还是伪影 | §五，F10、F17 |
| 实践 | 认知实践也是实践；回路三量（状态标量·通道权重·时间常数）；计划三内容与分辨率；例半群／类可重复（方案类定义、自然类假设）；单向对＝反向测度上界 ε（比值，不是增量符号）；判定靠识别条件 | §六，F11、F21 |
| 发展 | 本质关系判据要三样在手、不能用来发现层；时间窗决定关节点看得见看不见；改对了≠改成了 | §七，F16 |
| 层与窗口 | 层＝本质关系的封闭；构成系综相对、不传递、局部偏序；压缩要带失真度量；撤"系统质"一级；不闭合是连续量（记忆核比值）；窗口是认识的属性 | §一、§五 |
| 社会 | 立场落在 L2 结构假设；代价表 (K̂, L, δ) 公开≠客观；核的分配是权力的对象 | §八，F15 |
| 自由与三词 | 两轴四半不许合并；"必然"只留受限式；真实三条件给可指认不是存在；客观＝公共预言空间上的相容 | §九，F9、F13、F14 |

**没有进模式的**：本体论承诺的论证、规律形成的三种可能、时空与延时的推导细节（只留防错的那两句
结论）、F1–F21 的形式定义本身（模式只引条款号）、社会层与自由的完整展开。它们留在理论主稿里；
模式只留能在一次任务里被违反的部分。

## 模式自加的操作约定（理论不载）

这五条是为"能干活"加的，不是理论；与主稿冲突时以主稿为准：

| 约定 | 内容 | 为什么加 |
|---|---|---|
| 门槛分级 | 可回滚的局部改动一行结论；不可逆或跨版本／层级／作用域才走全套 | 主稿只管判据，不管一次任务该走多长 |
| 共模降级阶梯 | 换实现／换数据源／换外部探针；都做不到就标"单模型·共模未排除"，降为观察、不阻塞交付 | 主稿只给"共享同一副眼镜只算一个角度"，单人单机里没有第二角度 |
| 记录最低档 | 因果连续的记录在软件任务里降到"第三方只读可复现的一条命令" | 主稿给的记录形态（制备日志、追踪标记、守恒量传递）在纯软件任务里没有对应物 |
| 五问 | 缺哪个角度、哪部分是伪影、禁止哪些返回、补上后如何位移、换前向模型后还在不在 | 把 §四、§五 与 F9、F11、F12 收成一次可执行的审问 |
| 两张卡 | 自审一行（归类／依据／进不进更新／失败轴／下一个探针）、像核卡（像·核·位移·返回） | 判据要落成一行字才可核 |
